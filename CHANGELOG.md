# Changelog

All notable changes to skenv. Generated by [git-cliff](https://git-cliff.org) from Conventional Commits.
## v0.6.0 - 2026-09-26

### Breaking changes

- **cli:** task-oriented help, named argument errors, command contracts, new --visibility (#41) (e79d80f)
- **cli:** clone, use and list; init only starts a manifest (#42) (1833eb4)
- **import:** lead the report with outcomes, keep unmatched skills installed (#43) (0cd00a1)
- **manifest:** [user], [repository] and keyed [project] tables (ADR 0002) (#47) (93f6c0b)
- **sync:** checkout policy, config show and scope boundaries (ADR 0002) (#48) (cd11070)

### Bug fixes

- reject lint --hook with other modes; accurate doctor and --dry-run promises (#40) (299ff78)
## v0.5.0 - 2026-09-25

### Breaking changes

- **vendor:** rename bump to update (#31) (541f962)

### Features

- **import:** adopt an existing user-level skill setup (#35) (47873fb)
- **manifest:** gitlab: and codeberg: prefixes and self-hosted hosts declared in the manifest (#34) (b0d838f)
- **project:** project skills in a [project] section (#36) (820b325)
- **repo:** GitLab CI harness with repo.ci and --ci (#37) (b63412d)
- **import:** adopt a project's skills-lock.json with import --project (#39) (70dd645)

### Bug fixes

- **vendor:** key the vendor cache by the resolved clone URL and verify origin (#33) (e1b4ae3)
## v0.4.0 - 2026-09-25

### Breaking changes

- **cli:** move to cobra, multi-format tool config, generated command reference (#11) (93e9c7d)
- **manifest:** one skenv file with [repo] and [environment] sections (#12) (5f77311)
- **schema:** JSON Schemas for the skenv file and the tool config, with editor directives (#22) (24a904d)

### Features

- drop PowerShell completion, ship man pages in release archives (#14) (fa146d0)
- **manifest:** select skills of an own repository with skills and exclude (#23) (c0fecee)
- --format for init and repo init; init without a repository starts a manifest (#24) (5150165)

### Bug fixes

- **ci:** fail check-commits on an invalid revision range (#2) (7f369b6)
